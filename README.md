# Modern React & Tailwind Portfolio

A sleek, high-performance, and visually striking personal portfolio website built for **Manuga Pulmith Galbadage**. The site acts as a digital resume showcasing expertise in frontend web development, data analytics, and digital creation. 

Designed as a modern, dark-themed single-page application, it features a fluid glassmorphic UI, highly responsive layouts, and smooth background blob animations.

## 🚀 Key Features & Sections

* **Hero Section**: A bold introduction featuring a multi-color gradient header, quick summary, and interactive call-to-action buttons for viewing projects or downloading a CV.
* **About Me**: A breakdown of professional goals and core values as a tech enthusiast and self-learner.
* **Technical Skills**: An interactive matrix utilizing animated progress bars to visualize proficiency across web technologies and analytics.
* **Certifications**: A clean dual-column layout separating completed certifications (Google Data Analytics, HubSpot, Python) from ongoing learning paths.
* **Featured Projects**: A grid showcasing live web applications alongside projects currently in development.
* **Design Work**: A custom visual gallery highlighting educational promotional graphics created for local tuition classes.
* **Learning Journey**: A sleek vertical timeline charting major phases of academic and technical growth.
* **Contact Portal**: Multiple communication pathways, including custom integration triggers to send messages seamlessly via WhatsApp or Telegram.

## 🛠️ Tech Stack

* **Frontend Library**: React 18 (via CDN)
* **Compilation**: Babel (for runtime JSX parsing)
* **Styling**: Tailwind CSS (with highly customized theme configurations)
* **Animations**: Framer Motion
* **Icons**: Integrated inline SVGs & Simple Icons CDN
